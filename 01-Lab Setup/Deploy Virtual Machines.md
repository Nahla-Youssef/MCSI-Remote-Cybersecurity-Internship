# Lab Setup: Deploy Virtual Machines

---

## Objectives:

Research VirtualBox and its networking modes.

Build a two-VM lab (2x Kali Linux) on a bridged network.

Confirm connectivity between the VMs.

---

## Tools:

VirtualBox

Kali Linux ISO (x2)

---

## Steps:

1-Install VirtualBox.

2-Download the Kali Linux ISO.

3-Create two Kali VMs and configure both on a bridged network.

4-Check each VM's IP, then ping one VM from the other to confirm connectivity.

5- Validate: VirtualBox installed, both VMs set up, network configured (bridged), ping successful.
