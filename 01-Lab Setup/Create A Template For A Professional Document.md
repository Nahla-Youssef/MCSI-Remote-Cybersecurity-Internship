# Lab Setup: Create A Template For A Professional Document

---

## Objectives:

Learn to structure a professional Word document the way it would be delivered in a real cybersecurity/consulting engagement.

Build a cover page and consistent header/footer branding (logo + page numbers) across the whole document.

Practice generating an automatic Table of Contents from heading styles instead of typing one by hand.

Maintain a Revision History table to track document versions, authors, and changes over time.

Practice sourcing, quoting, and citing a reputable external source correctly (APA style), including a References section.

Practice embedding an image with a properly formatted, attributed caption.

---

## Tools:

Microsoft Word / Google Docs — native cover page, header/footer, and auto-generated Table of Contents features.

docx (Node.js library) — used here to generate the .docx file programmatically.

LibreOffice (soffice) + pdftoppm — used to render the document to PDF/images for visual verification before delivery.

CISA.gov (Cybersecurity and Infrastructure Security Agency) — reputable source used for the in-text citation and reference entry.

---

## Steps:
Cover page & header/footer — Designed a cover page with title, author name, date, and a custom logo; placed the same logo in the document header, and a page-number footer (Page X of Y) on every page.

Table of Contents & page numbers — Applied Word/Google-Docs-compatible heading styles (Heading 1 / Heading 2) to every section so a Table of Contents can auto-generate and stay in sync; page numbers live in the footer.

Revision History — Added a table with Version Number, Name, Date, Description of Changes columns, and recorded the initial revision (v1.0) with my name and today's date.

Citations & References — Selected a short passage from CISA's guidance on social engineering/phishing, quoted it with an APA in-text citation, and listed the full source in a References section at the end.

Image & caption — Inserted a cybersecurity-related image (an original access-control/padlock graphic) and added a formatted, attributed caption beneath it (Figure 1. ...).
